# Assets

> Part of the [codebase guide](index.md). Every file below is described in plain words; the [architecture page](../architecture.md) explains how the parts work together.

Every binary file the product ships: the icons (compiled into one SVG sprite at build time, with a generated list of icon names), the images (with their sizes and alt text), and the font stylesheet. No React.

## Every file

### `packages/asset/`

| File | What it does |
|---|---|
| `asset.d.ts` | Tells TypeScript that importing an image or font file gives back a URL string. Build tooling, so it sits outside `src/`. |
| `build-sprite.mjs` | Runs before every build. Combines every icon in `src/icon/svg/` into one sprite file and regenerates `icon-registry.ts`, the list of icon names. Fails the build if an icon hard-codes a colour or has no `viewBox`. |
| `package.json` | The package manifest: its name, its build, test and type-check scripts, and its dependencies. Versions come from the workspace catalog. |
| `tsconfig.json` | TypeScript settings. Extends a shared preset from `tooling/tsconfig` and type-checks the tests too. |
| `tsup.config.ts` | Build settings: bundles `src/` into `dist/` as ES modules with type declarations. |
| `vitest.config.ts` | Test runner settings. Resolves sibling packages to their source, so tests never run against a stale build. |

### `packages/asset/src/`

| File | What it does |
|---|---|
| `index.ts` | The package's public entry point. Re-exports what other packages may use, and contains no logic. |

### `packages/asset/src/font/`

### `packages/asset/src/icon/`

| File | What it does |
|---|---|
| `icon-registry.ts` | Generated by `build-sprite.mjs`. `ICON_NAMES` and the `IconName` type: every icon the sprite holds, so asking for a missing icon fails to compile. |
| `index.ts` | Folder index: re-exports the files beside it, so other folders import the folder rather than its files. |
